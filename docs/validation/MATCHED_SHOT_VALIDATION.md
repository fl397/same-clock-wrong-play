## Analysis definitions

Machine-readable rules: `configs/matched_shot_audit.yaml` (authoritative). The rules below were fixed before the comparison was computed.

**Question addressed.** The Figure 1 comparison uses a naive-join sample (27,563 shots) with a corrected-join sample (64,764 shots) from the same 437 validated games; eligibility differs because the naive window rarely labels ≥ 5 frames to the shooting team. It is fair to ask whether clock correction removes the apparent spacing–eFG gradient or whether the change in *which shots enter* does. The answer must come from a common shot sample.

**Common shot set.** `S_intersection` = shot keys present on both axes of the per-shot spacing table (naive eligibility ≥ 5 labelled frames AND corrected eligibility ≥ 5 labelled frames). Identity key = the producer's row identity `(game_id, period, secs, shot_value, made)`; no `actionNumber` exists in the rows and no fuzzy matching is used. Keys occurring more than once within an axis are excluded from `S_intersection` (cannot be matched one-to-one); counts reported. No additional filtering.

**Two axes on the same shots.** For every common shot the two hull areas already computed by the spacing producer (naive-window hull; corrected-window hull). Same spacing definition, no new geometry, no non-shooter variant, no 3PA claim.

**Quartile rule.** Per axis separately: boundaries = 25/50/75 % quantiles of that axis's hull area over `S_intersection` (`pandas.quantile` + `numpy.digitize`, as the producer); all common shots assigned; report N, eFG = (made + 0.5·made·3PA)/n per quartile, Q4 − Q1, and Spearman ρ across the four quartile means (descriptive). No regression.

**Secondary fixed-rank check (diagnostic only).** Quartiles assigned once by naive ranks on `S_intersection`; within those memberships: naive eFG by quartile and corrected-window hull mean/median by the same groups.

**Decision rule (operationalised before results; reference = original naive Q4 − Q1 = 0.0938).**
- CASE 1 MATCHED_SAMPLE_CONFIRMS_ARTIFACT: naive Q4 − Q1 on `S_intersection` ≥ 2/3 × 0.0938 (0.0625) AND naive quartile eFGs monotone non-decreasing AND corrected Q4 − Q1 on `S_intersection` ≤ 1/3 of the naive intersection value (or negative) → current headline defensible.
- CASE 3 SAMPLE_COMPOSITION_DOMINATES: naive Q4 − Q1 on `S_intersection` < 1/3 × 0.0938 (0.0313) → the Figure 1 headline would not be supported.
- CASE 2 MIXED_MEASUREMENT_AND_SELECTION: otherwise → public wording "Naive clock joining alters both analytical eligibility and the apparent spacing–efficiency relationship."

**Reproduction gate.** The per-shot cache is not redistributed; the unchanged producer is re-run and its regenerated aggregate CSV must equal the shipped spacing/eFG table (n exactly; efg / hull / 3PA share to 1e-9) before any per-shot row is read. On failure: STOP and report.
